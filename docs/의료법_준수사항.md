# 의료법령 준수 사항

## 아주 정신과 차트 (HospitalChart)

---

## 1. 의료법 제22조 — 진료기록부 보존

### 보존 기간
| 기록 종류 | 보존 기간 |
|---------|--------|
| 진료기록부, 조산기록부 | **10년** |
| 수술기록 | 10년 |
| 처방전 | 2년 |
| 간호기록 | 5년 |
| 검사 기록 | 5년 |

### 구현
- `chart_records.is_deleted`, `patients.is_deleted`: 소프트 삭제 (true = 비표시)
- **DELETE RLS 정책으로 물리 삭제 완전 차단**
- 처방전(`prescriptions`): 2년 보존 정책 적용 예정 (pg_cron 스케줄러)

---

## 2. 의료법 제23조 — 전자의무기록

### 요건
- 접근 권한 제한 (역할 기반 접근 제어)
- 접근 이력 보존
- 전자서명 (처방전 등)

### 구현
- **RLS (Row Level Security)**: staff_role에 따라 테이블 접근 제한
  - secretary(비서): 차트 열람 불가
  - nurse/pa: 조회·간호기록 작성 가능, 처방 불가
  - resident/attending: 전체 진료 기능
  - superadmin: 모든 기능
- **audit_log 테이블**: 모든 INSERT/UPDATE + 환자 조회(VIEW) 자동 기록
  - 누가·언제·어떤 차트를 접근했는지 영구 보존
  - 삭제 RLS로 audit_log 삭제 차단
- **전자서명**: `prescriptions.signed_at + prescriber_id`
  - 미서명 처방(draft)은 약국 전달 불가

## 3. 정신건강복지법 — 입원 관리

### 입원 유형 (§31, §41, §43, §44)
| 유형 | 법조항 | 요건 | 특이사항 |
|-----|-------|-----|-------|
| 자의입원 | §31 | 환자 본인 신청 | 언제든 퇴원 청구 가능 |
| 보호의무자 입원 | §41 | 보호의무자 2인 동의 + 정신건강의학과 전문의 2인 진단 | 최초 3개월, 연장 심사 |
| 응급입원 | §43 | 자타해 위험, 72시간 이내 | 72시간 내 서류 구비 필수 |
| 행정입원 | §44 | 시장·군수·구청장 결정 | 국가 행정 절차 |

### 정기 심사 (§55)
- 비자의 입원 환자는 **정기적 심사** 의무
- 응급입원: 72시간 후
- 보호의무자/행정입원: 최초 1개월, 이후 3개월, 6개월마다
- `admissions.next_review_date`: DB 트리거로 자동 계산
- 메인 화면 툴바: 오늘 심사 예정 환자 건수 알림

## 4. 개인정보보호법 — 민감정보 보호

### 환자 개인정보 분류
| 정보 | 등급 | 처리 방법 |
|-----|-----|--------|
| 이름 | 민감 | DB 암호화(AES-256) + 화면 마스킹 |
| 생년월일 | 일반 | 평문 저장 |
| 주민등록번호 | **민감** | bcrypt 해시만 저장 (복호화 불가) |
| 진단명 | **민감** | RLS로 접근 제한 |
| 처방 | **민감** | RLS로 접근 제한 |

### 동의 이력
- `patient_consents` 테이블: 수집·이용·제공 동의 이력 보관
- 동의 철회 시 `consented=false` 기록 (삭제 금지)
